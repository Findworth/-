1. ROAS = Return on Ad Spend（广告支出回报率）
    ROAS = 广告带来的收入 ÷ 广告支出
    你花了1000元投Meta广告，通过广告卖货赚了5000元
    ROAS = 5000 ÷ 1000 = 5
    意味着：每花1元广告费，带来5元收入

2. CTR = Click-Through Rate（点击率）
    CTR = 点击次数 ÷ 曝光次数
    你投放了1000次广告，有100次点击，则CTR = 100 ÷ 1000 = 0.1
    意味着：每100次曝光，有10次点击

3. 独立站
    - 独立站是指企业自己搭建的网站，网站的所有权和运营权都在企业自己手中，企业可以自由地进行网站的设计、开发、维护和优化。
    - 需要自己引流（Meta/Google广告等）
    - 核心价值是‘数据主权+品牌积累’。
    - DTC品牌（Direct-to-Consumer） 直接卖给消费者，没有中间商

4. 跨境电商SAAS
shopify:
1. 配置支付网关：在后台的“设置”中，选择“支付”选项，添加并配置您希望使用的支付方式，如信用卡支付、PayPal等。
2. 设置配送选项：在“设置”中，选择“配送和送货”选项，定义配送区域、运费和配送方式。
3. 访问模板商店：在Shopify后台，点击“在线商店”下的“模板”选项，浏览免费和付费模板。
    选择合适的模板：根据您的品牌形象和业务需求，选择最适合的模板。
4. 域名设置：购买域名：您可以通过Shopify直接购买域名，或使用第三方域名提供商购买。连接域名：如果使用第三方域名，按照Shopify提供的指南，将域名指向您的Shopify商店。
5. 搜索引擎优化（SEO）：优化商店的元标签、产品描述和图片ALT标签，提高在搜索引擎中的排名。
